# Сайт EUES: як опублікувати та налаштувати

Сайт статичний. Сервер і база даних не потрібні. Увесь вміст лежить у цій папці:

```
index.html                    сайт (усі розділи на одній сторінці)
img/                          прапор ЄС і декоративні елементи
files/tema-01.pdf … 15.pdf    презентації для перегляду
files/tema-01.pptx … 15.pptx  презентації для завантаження
files/EUES_vsi_temy_PDF.zip   усі теми одним архівом
```

---

## 1. Публікація на GitHub Pages (безкоштовно, без обмеження терміну)

1. Зареєструйтеся на https://github.com (безкоштовний акаунт).
   Ім'я користувача стане частиною адреси сайту, наприклад `eues-mdu` → `https://eues-mdu.github.io`.
2. Натисніть **+ → New repository**:
   - **Repository name:** `eues-mdu.github.io` (замість `eues-mdu` підставте своє ім'я користувача). Тоді сайт відкриватиметься за короткою адресою без додаткового шляху.
   - **Public**.
   - Натисніть **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file**.
4. Розпакуйте архів сайту. Виділіть **вміст** папки (index.html, img, files, README.md і файл .nojekyll), а не саму папку, і перетягніть у вікно браузера.
   - Якщо GitHub не прийме всі файли за раз, завантажте спершу index.html та img, потім вміст files двома-трьома порціями. Папку files при цьому створіть, дописавши `files/` до назви файлу.
5. Натисніть **Commit changes**.
6. Відкрийте **Settings → Pages**. У полі **Source** оберіть **Deploy from a branch**, у полі **Branch** — `main` і `/ (root)`, потім **Save**.
7. За 1–3 хвилини сайт стане доступний за адресою `https://<ім'я>.github.io`.

**Оновлення матеріалу.** Завантажте новий файл із тією самою назвою (наприклад, `files/tema-05.pdf`). Він замінить старий.

## 2. Підключення форми зворотного зв'язку (Google Форма)

Відгуки збиратимуться у вашій Google Формі та в Google Таблиці. Студентам не потрібен жоден акаунт.

### Крок 1. Створіть форму на https://forms.google.com

Додайте 6 питань у такому порядку:

| Питання                         | Тип                    |
|---------------------------------|------------------------|
| Ім'я                            | Коротка відповідь      |
| E-mail                          | Коротка відповідь      |
| Хто ви?                         | Коротка відповідь      |
| Тема                            | Коротка відповідь      |
| Оцінка                          | Коротка відповідь      |
| Відгук                          | Абзац                  |

- Варіанти вибору на сайті вже є, тому в самій формі всі питання мають бути текстовими.
- Жодне питання не позначайте як обов'язкове.

### Крок 2. Отримайте ідентифікатори полів

1. У формі натисніть **⋮ → Отримати попередньо заповнене посилання** (Get pre-filled link).
2. Впишіть у кожне поле будь-що, наприклад 1, 2, 3, 4, 5, 6, і натисніть **Отримати посилання → Копіювати**.
3. Ви отримаєте посилання на зразок:

```
https://docs.google.com/forms/d/e/1FAIpQLSc...XYZ/viewform?usp=pp_url&entry.111111=1&entry.222222=2&...
```

- Частина до `/viewform` — це адреса форми.
- `entry.111111` тощо — ідентифікатори полів у тому порядку, у якому ви їх заповнювали.

### Крок 3. Впишіть дані в index.html

Відкрийте `index.html` у будь-якому текстовому редакторі (або прямо на GitHub через іконку олівця). Знайдіть блок `НАЛАШТУВАННЯ` і заповніть його:

```js
const CONFIG = {
  coordinatorEmail: "n.balabanova@mu.edu.ua",
  googleForm: {
    action: "https://docs.google.com/forms/d/e/1FAIpQLSc...XYZ/formResponse",
    fields: { name:"entry.111111", email:"entry.222222", role:"entry.333333",
              topic:"entry.444444", rating:"entry.555555", message:"entry.666666" }
  }
};
```

- Зверніть увагу: в кінці адреси форми замість `viewform` має бути **`formResponse`**.
- Відповіді переглядайте у формі на вкладці **Відповіді**. Там можна ввімкнути сповіщення на пошту та зв'язок із Google Таблицею.

**Якщо форму ще не підключено, але e-mail вказано,** кнопка «Надіслати» відкриє поштовий клієнт відвідувача з уже заповненим листом.

## 3. Що ще можна змінити

- **Команда.** Масив `TEAM` у `index.html`.
- **Фото команди.**
  1. Завантажте фото в папку `img/team/` (на GitHub: Add file → Upload files, у назві допишіть `img/team/`).
  2. Біля потрібної людини в масиві `TEAM` впишіть шлях: `photo:"img/team/balabanova.jpg"`.
  3. Найкраще підходять квадратні фото від 300×300 px. Назви файлів — латиницею, без пробілів.
  Поки фото немає, на сайті показуються ініціали.
- **Тексти розділів.** Звичайний HTML у тому ж файлі.
- **Нова тема або новий файл.** Масив `TOPICS` (назва, кількість слайдів, план лекції) і файли в папці `files/` з назвою `tema-NN.pdf` / `tema-NN.pptx`.
